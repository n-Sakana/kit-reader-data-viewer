## 検証用コードを直した回数・途中で止めた試行

| 対象 | 修理回数 | 理由・扱い |
|---|---:|---|
| `Start-Capture.ps1` | 1 | 画面外ポリシーのコンパイルにSystem.Xaml参照が不足。アプリ開始前に停止し、参照追加後に撮影 |
| `export.cjs` | 1 | 最初の条件値をTRUEと取り違え、CSVが0行。画面の実値「済」へ直して80行。誤ったCSVと画面も証跡として保持 |
| `Export-PowerPoint.ps1` | 1 | ExportAsFixedFormatのCOM引数で失敗。SaveAsのPDF形式へ変更して正常出力 |
| 自作PDF全文照合 | 1、その後中止 | P15の▶・◀はPDFの文字抽出に出ないため、実際のPDF描画を確認して例外扱いを追加。その後P23のバックスラッシュが円記号として抽出されて停止。さらに直すことはせず、全文照合の成功を主張しない。P15・P23のPDF描画は読めることを確認 |
| `reimport.cjs` | 0、未完了 | 二段目の確認を進めずReaderを終了。結果ファイルなし。終了コード0だけで再取込成功とは扱わない |
| 既存の製品検査 | 0 | 修正・削除・緩和・skipなし。この説明書制作で全回帰を再実行してはいない |

PDF読取ライブラリはNix環境でlibstdc++の場所を必要としたため、実行時だけライブラリパスを指定しました。Python本体やシステムのrebuildは行っていません。大きなPPTXのAPI転送はHTTP 400になったため、自分の専用ディレクトリだけを公開する一時HTTPサーバーからノートへ渡しました。転送用サーバーは終了済みです。

画像一覧を作る道具には最初にプロジェクト全体のパスを渡して空の一覧になり、正しいimagesフォルダを渡し直しました。道具のコードは修正していません。SVGの最終品質検査では、初回に画像一覧のStatus値の形式と6ページの囲み範囲等を直し、冗長な文字指定を公式のcompactツールで整理しました。これは制作物の修正であり、検査の期待値を緩めたものではありません。

## 未確認の範囲

外部アプリの実UIA読取・前面化、実機器、本番データ・共有サーバー、複数PC、他DPI・IME、性能、固定版は未確認です。VBSの通常起動経路、再取込完了、元の内容変更による状態リセット、未処理へ戻して再送する一周も今回の実測ではありません。スライドと出典台帳で、実画面の確認とコード・文書による説明を分けています。

PDFの全文文字抽出による照合は不成立です。今回の目視はWindows PowerPoint 2021による出力と、PDFの2ページの再描画です。別のOffice・LibreOffice・Macでの表示を検収したとはしていません。
